# Changelog

История изменений плагинов Lampa Plugins / Lampa Plugins change history.

## Lampa Keyboard Fix — v0.1.0

Первый выпуск / Initial release.

### Исправления

- Вертикальная навигация ↑/↓ выбирает ближайшую по горизонтали клавишу в соседнем ряду.
- Исправлены пропуск рядов и преждевременный переход в историю поиска.
- Возврат ↑ из истории поиска направляет фокус на нижний ряд клавиатуры.

### Проверено

KICKPI KP1, Android TV 14, прошивка v14.7.9314, Lampa 3.4.7, APK 1.13.6-586. Все 8 ручных тестов автора пройдены, включая английскую раскладку, цифры и специальные символы. Другие конфигурации не проверены. Полная конфигурация и таблица тестов — в [README](README.md#testing).

### Fixes

- Vertical ↑/↓ navigation selects the horizontally nearest key in the adjacent row.
- Fixed skipped rows and premature jumps to search history.
- Pressing ↑ in search history returns focus to the bottom keyboard row.

### Verified

KICKPI KP1, Android TV 14, firmware v14.7.9314, Lampa 3.4.7, APK 1.13.6-586. All 8 author-reported manual tests passed, including English, numbers and special characters. Other configurations are unverified. See [README](README.md#testing) for details.
