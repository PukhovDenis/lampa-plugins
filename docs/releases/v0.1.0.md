# Lampa Keyboard Fix v0.1.0

## Русский

Первый выпуск исправления навигации по встроенной клавиатуре Lampa с пульта.

- ↑/↓ переводят фокус на ближайшую по горизонтали клавишу соседнего ряда.
- Устранены пропуск рядов и преждевременный переход в историю поиска.
- ↑ из истории поиска возвращает фокус на нижний ряд клавиатуры.
- Не требует изменения APK; без собственных сетевых запросов, записи в хранилище и сторонних зависимостей.

Проверено автором: KICKPI KP1, Android TV 14, сборка UKG3.251130.001.9314, прошивка v14.7.9314, Lampa 3.4.7, APK 1.13.6-586, встроенная клавиатура и пульт. Пройдены все 8 ручных тестов, включая английскую раскладку, цифры и специальные символы. Совместимость с другими конфигурациями не проверена.

**Установка:** добавьте в расширения Lampa URL ниже и перезапустите приложение.

https://pukhovdenis.github.io/lampa-plugins/lampa-keyboard-fix.js

**Удаление:** отключите или удалите расширение и полностью перезапустите Lampa.

## English

Initial release of the remote navigation fix for Lampa's built-in keyboard.

- ↑/↓ select the horizontally nearest key in the adjacent row.
- Fixed skipped rows and premature jumps to search history.
- ↑ in search history returns focus to the bottom keyboard row.
- No APK modification, network requests of its own, storage writes or third-party dependencies.

Verified by the author on KICKPI KP1, Android TV 14, build UKG3.251130.001.9314, firmware v14.7.9314, Lampa 3.4.7, APK 1.13.6-586, built-in keyboard and remote. All 8 manual tests passed, including English, numbers and special characters. Other configurations are unverified.

**Install:** add the URL above in Lampa's extensions settings and restart.
**Remove:** disable or remove the extension and fully restart Lampa.
